## Exercise 1: Matrix Size and Entries

Given:

$$A=\begin{pmatrix}2&-1&3\\0&4&5\end{pmatrix},\quad B=\begin{pmatrix}1&0\\-2&3\\4&1\end{pmatrix}$$

### 1. Matrix dimensions

Matrix A has 2 rows and 3 columns, so its size is $2\times3$.

Matrix B has 3 rows and 2 columns, so its size is $3\times2$.

### 2. Matrix entries

$$a_{12}=-1,\quad a_{23}=5$$

$$b_{21}=-2,\quad b_{32}=1$$

The first index indicates the row, and the second index indicates the column.

### 3. Row and column vectors

The second row of A is:

$$(0,4,5)$$

The first column of B is:

$$\begin{pmatrix}1\\-2\\4\end{pmatrix}$$

### Verification

All entries and vectors match their positions in the original matrices.
